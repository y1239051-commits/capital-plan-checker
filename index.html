📌 GitHub 使用說明

通過驗證的 ODS 檔案自動上傳到 passed/ 資料夾。若同單位重新上傳並通過，新版覆蓋舊版，GitHub 保留所有版本歷史。

建立 Repository 步驟：

① github.com → 右上角 ＋ → New repository → 名稱填 capital-check，選 Public，勾 Add README → Create

② Settings → Pages → Branch: main / root → Save

③ Add file → Upload files → 上傳本工具（改名為 index.html）

完成後即可透過 https://帳號.github.io/capital-check/ 讓全縣使用。
